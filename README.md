# 🌐 Personal Developer Portfolio

A fully responsive, modular, single-page personal portfolio website designed to showcase my skills, projects, research papers, certificates, and professional experience.

🔗 **Live Site:** [sraboni.dev](https://sraboni.dev/)

---

## 🛠️ Main Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Fonts:** Custom CSS, Responsive Layout Design
- **Hosting & Infrastructure:** Cloudflare Pages (Custom Domain Integration)

---

## ✨ Key Features

- 📱 **Fully Responsive:** Smooth layout that seamlessly adapts to desktop, tablet, and mobile screens.
- 📂 **Modular Structure:** Modular architecture built with separate HTML/CSS sections for clean maintainability.
- 🔬 **Research & Papers:** Dedicated section showcasing research works and academic credentials.
- 📜 **Certifications & CV:** Direct access to verified certificates and downloadable CV.
- ⚡ **Interactive UI:** Dynamic UI components driven by vanilla JavaScript.

---

## 📦 Dependencies & Tools

- **Local Development Server:** Node.js / `serve` (or Live Server)
- **Deployment Platform:** Cloudflare Pages

---

## ⚙️ How to Run Locally

Follow these steps to set up and run the project locally on your machine:

1. **Clone the repository:**
   git clone https://github.com/nafisasraboni/portfolio-final.git

2. **Navigate to the project directory:**
   cd portfolio-final

3. **Install dependencies:**
   npm install

4. **Start the local server:**
   npm start
   *(Or run npx serve / VS Code Live Server)*

5. **Open in Browser:**
   Visit http://localhost:3000/ in your Chrome browser.
